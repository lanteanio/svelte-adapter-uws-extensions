# Security policy

Security fixes target the current stable npm `latest` release and the current
prerelease `next` release. Reproduce on the relevant supported release when possible.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/lanteanio/svelte-adapter-uws-extensions/security/advisories/new).
The repository enables this route; a GitHub account is required. If it is
unavailable, open a public issue asking for a private channel without including
vulnerability details. Do not publish exploit code or affected deployment data.

Include the package and backend versions, attacker prerequisites, impact, a
minimal reproduction, and any workaround. Remove secrets and unrelated personal
data. Coordinate disclosure in the private report. Response time depends on the
report and maintainer availability; there is no response-time guarantee.
